# Yui 预设与可选配套 · 0.12.0

文件由本项目独立编写，没有复制其他作者的提示词或宏实现。本套随 0.12.0 发布，需搭配 0.12.0 扩展代码。

## yui-phone-default-preset.json：手机聊天预设

手机桌面 → 设置 → 聊天预设 → 导入预设 → 检查 → 确认导入 → 使用此预设 → 保存预设设置。

内容与内置 Yui 默认一致，导入后成为可编辑副本，可增删文字条目、开关、调整顺序。也可直接复制内置默认；不需要额外导入世界书。人物资料、手机历史和表情包/转账协议由程序补齐，不包含在可导出的文字条目里。

nuopreset 中没有正文的 marker 不等于已实现的功能。未知变量不会自动替换；导入预览会说明兼容情况。世界书 JSON 与预设 JSON 不能混用导入入口。

## yui-phone-story-worldbook.json：可选正文补充规则

在酒馆世界书库中导入，按需挂当前角色/聊天或全局，再启用需要的条目；文件默认关闭。不建议重复勾选到手机人物的参考书中。

这是静态规则，不是变量书，不会读取数据。“将此人的手机聊天提供给正文”开关才决定是否由扩展提供当前好友已保存交流。正文会把转账当作故事中发生的交易，按记录状态承接；程序没有现实支付能力。

当前没有必须挂全局的变量书，也没有注册其他手机的宏。手机历史不会随正文备选切换或回退自动回滚。

## yui-phone-display-regex.json：可选显示过滤

在酒馆“正则”扩展导入此 JSON 数组，默认启用、仅处理 AI 输出的显示。模型误回显独立整行的完整 <yui_phone_reference_v1> 区块时才隐藏；正常没有视觉变化。不删除存档，不过滤发送给模型的提示词，不处理普通 HTML 或其他作者标签。

Yui 读取正文时也会去掉完整的自身参考回显，避免循环带回手机。此功能需要 0.12.0 代码；单独导入正则不会新增互通、识图或分支功能。

## 隐藏楼层与验收

开启人物“参考当前酒馆剧情”后，最近 N 条包含有正文的隐藏消息；预览给出隐藏条数。工具、明确系统角色和已标记插件内部消息跳过；只读当前已加载存档的当前备选。不保证识别所有未标记第三方文本。

模拟测试记录见项目 TESTING.md；完整 TT/ST 的预设导入与正则显示效果仍待实测。此前基础通讯录的 TT 通过不扩大为这些功能已通过。
