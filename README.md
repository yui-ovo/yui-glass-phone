# Yui · 灰玻璃小手机

SillyTavern / TauriTavern 小手机美化预览，v0.3.0。

沿用 Yui 提供的正文手机外壳与聊天样式：深灰半透明磨砂、灵动岛、320 × 550 尺寸、圆形头像和灰阶气泡。新增桌面、消息列表与页面导航。

## 安装与打开

1. 在酒馆的扩展管理中选择「安装扩展 / 从 URL 安装」。
2. 粘贴仓库地址：`https://github.com/yui-ovo/yui-glass-phone`。
3. 安装完成后刷新或重新打开酒馆。
4. 点击屏幕右侧靠下的「小手机」按钮。

更新时在酒馆扩展管理中更新本扩展，然后刷新。无需构建、API 密钥或其他扩展。

## v0.3.0 更新

移除英文副标题及底部导航文字，保留图标与无障碍中文名称；顶栏上移、底栏下移，搜索框缩小。消息页可搜索示例聊天文字和联系人。

更新此小手机后，点击酒馆扩展管理窗口的「关闭」，会在窗口完成关闭后检查本扩展的本地版本；与当前运行版本不同才刷新。不读取聊天或调用 AI。首次从旧版升到 0.3.0 仍需手动刷新一次来加载这个逻辑；之后生效。只针对本扩展的版本变更，不替其他扩展管理更新。支持采用标准 `dialog.popup` 管理窗口的 ST / TT；真机结果仍需验收。

## v0.2.0 更新

消息应用内新增固定底栏「消息、联系人、朋友圈、我」，沿用深灰磨砂样式。联系人可以搜索并进入示例聊天；朋友圈展示封面与示例动态；「我」展示资料、钱包、收藏、相册和设置入口。四个主页面显示底栏，进入聊天时隐藏；从联系人进入聊天后返回联系人，从「我」进入设置后返回「我」。点赞、评论、发动态、钱包等仍是占位预览。

## 这一版可以看什么

- 桌面：深灰渐变壁纸、系统时间、消息 / Thread / 设置三个图标。
- 消息：示例联系人列表、搜索、私聊、三人群聊、聊天资料。
- 聊天样式：文字、语音文字卡、图片描述卡、转账卡、时间与系统提示。
- Thread：占位页面。
- 设置：外观页面，以及两种灰色渐变的临时预览切换。
- 点击底部横条回桌面，左上角返回上一级，机身外右上角关闭。

**本版只做美化。** 所有联系人、未读数和消息都是虚构示例；不会读取、修改酒馆聊天，不发送消息，不调用 AI，不保存数据。桌面显示设备当前时间，聊天示例时间固定。发送和附件按钮仅显示预览提示，语音与转账卡没有真实功能。

## 手机适配

保留原外壳尺寸；在窄屏和低高度视口中缩短可用区域，让内容内部滚动。采用安全区边距、动态视口高度和局部样式隔离，减少与酒馆主题冲突。以 iPhone 14 Pro 竖屏为主要设计目标。

采用标准前端扩展清单和浏览器 DOM，无 Node 后端依赖。实际 iOS Safari / TauriTavern 真机效果仍需用户安装验收，不代表所有版本均已验证。

## 本地预览

用任意静态 HTTP 服务托管此目录，然后打开 `preview.html`。不要直接以 `file://` 打开，浏览器可能拦截模块脚本。
